# Model 2: Sector Day-Start Allocation Forecaster — Feature & Input Specification

## 1. Overview & Modeling Scope
The **Sector Day-Start Allocation Forecaster** predicts Bank of America's (BofA / `MLB`) cross-sectional capital allocation and sector rotation across all 26 tracked BIST industry sectors during **Window 1 (09:55 – 10:30 TRT)** on trading day $T$.

All input features are strictly constructed from completed historical market sessions up to **$T-1$ Close (18:10 TRT)**, guaranteeing **zero lookahead bias / data leakage**.

---

## 2. Target Variables (Day $T$, Window 1, Sector $s$)

| Target Variable | Type | Mathematical Formulation | Role & Description |
| :--- | :--- | :--- | :--- |
| `target_sector_open_net_flow_tl` | `float64` | $y_{s, T} = \sum_{i \in \text{Trades}_{T, \text{W1}, \text{MLB}, \text{Sector } s}} (\text{Buy}_i - \text{Sell}_i)$ | **Continuous Sector Target**: Net executed flow in TL by BofA in sector $s$ during Window 1. |
| `target_sector_open_direction` | `str` | $\begin{cases} \text{BUY}, & \text{if } y_{s, T} > 0 \\ \text{SELL}, & \text{if } y_{s, T} \le 0 \end{cases}$ | **Binary Direction**: Derived directional label for sector classification and hit-rate scoring. |

---

## 3. The 7 Sector Quantitative Feature Clusters (32 Features)

### Cluster 1: Sector Closing Momentum (Window 4: 17:00 – 18:10 TRT)
*Unfinished institutional sector benchmark orders (MOC/VWAP) carry over into next morning's sector opening auction.*

| Feature Name | Type / Lag | Mathematical / SQL Formulation | Default / Coalesce | Microstructure & Behavioral Rationale |
| :--- | :--- | :--- | :--- | :--- |
| `feat_sector_bofa_w4_net_flow_tl` | Flow ($T-1$) | $\text{Buy}_{\text{MLB}, s, \text{W4}} - \text{Sell}_{\text{MLB}, s, \text{W4}}$ | `0.0` | BofA's closing window net flow in sector $s$. Heavy buying signals morning continuation. |
| `feat_sector_bofa_w4_turnover_tl` | Flow ($T-1$) | $\text{Buy}_{\text{MLB}, s, \text{W4}} + \text{Sell}_{\text{MLB}, s, \text{W4}}$ | `0.0` | Closing window gross turnover in sector $s$ confirming conviction behind sector move. |

---

### Cluster 2: Sector Competitor Posture & Flow Imbalance
*Sector order flow is adversarial. Divergence between BofA and domestic market makers reveals sector liquidity imbalances.*

| Feature Name | Type / Lag | Mathematical / SQL Formulation | Default / Coalesce | Microstructure & Behavioral Rationale |
| :--- | :--- | :--- | :--- | :--- |
| `feat_sector_top5_w4_net_flow_tl` | Flow ($T-1$) | $\sum_{b \in \text{Top5}} \text{Net Flow}_{b, s, \text{W4}, T-1}$ | `0.0` | Top 5 domestic brokerages' closing window net flow in sector $s$. |
| `feat_sector_bofa_vs_top5_w4_delta_tl` | Delta ($T-1$) | $\text{Flow}_{\text{MLB}, s, \text{W4}} - \text{Flow}_{\text{Top5}, s, \text{W4}}$ | `0.0` | Closing flow divergence in sector $s$ (signals institutional squeeze vs domestic resistance). |
| `feat_sector_top5_prev_day_net_flow_tl` | Flow ($T-1$) | $\sum_{b \in \text{Top5}} \text{Net Flow}_{b, s, \text{Day}, T-1}$ | `0.0` | Top 5 domestic brokerages' full-day net flow in sector $s$. |
| `feat_sector_bofa_vs_top5_daily_delta_tl` | Delta ($T-1$) | $\text{Flow}_{\text{MLB}, s, \text{Day}} - \text{Flow}_{\text{Top5}, s, \text{Day}}$ | `0.0` | Full-day flow divergence between BofA and domestic institutions in sector $s$. |

---

### Cluster 3: Sector Market Dominance & Wallet Share
*Measures BofA's pricing power within sector $s$ and the prominence of sector $s$ in BofA's daily execution book.*

| Feature Name | Type / Lag | Mathematical / SQL Formulation | Default / Coalesce | Microstructure & Behavioral Rationale |
| :--- | :--- | :--- | :--- | :--- |
| `feat_sector_bofa_prev_day_net_flow_tl` | Flow ($T-1$) | $\text{Buy}_{\text{MLB}, s, T-1} - \text{Sell}_{\text{MLB}, s, T-1}$ | `0.0` | Total full-day net flow executed by BofA in sector $s$ on $T-1$. |
| `feat_sector_bofa_prev_day_turnover_tl` | Flow ($T-1$) | $\text{Buy}_{\text{MLB}, s, T-1} + \text{Sell}_{\text{MLB}, s, T-1}$ | `0.0` | Gross turnover generated by BofA in sector $s$ on $T-1$. |
| `feat_sector_bofa_market_share` | Ratio ($T-1$) | $\frac{\text{Turnover}_{\text{MLB}, s, T-1}}{\text{Turnover}_{\text{Market}, s, T-1}}$ | `0.0` | BofA's market share of total sector turnover (quantifies pricing power). |
| `feat_sector_bofa_share_of_wallet` | Ratio ($T-1$) | $\frac{\text{Turnover}_{\text{MLB}, s, T-1}}{\text{Turnover}_{\text{MLB}, \text{Total}, T-1}}$ | `0.0` | Percentage of BofA's entire daily volume dedicated to sector $s$ (priority weighting). |

---

### Cluster 4: Sector Multi-Day Inventory Saturation
*Sector-specific portfolio exposure ceilings. Prolonged single-sector accumulation triggers portfolio rebalancing.*

| Feature Name | Type / Lag | Mathematical / SQL Formulation | Default / Coalesce | Microstructure & Behavioral Rationale |
| :--- | :--- | :--- | :--- | :--- |
| `feat_sector_bofa_cum_net_flow_5d_tl` | Rolling ($T-1$) | $\sum_{k=1}^5 \text{Net Flow}_{\text{MLB}, s, T-k}$ | `0.0` | 5-day rolling cumulative net flow of BofA in sector $s$. |
| `feat_sector_top5_cum_net_flow_5d_tl` | Rolling ($T-1$) | $\sum_{k=1}^5 \sum_{b \in \text{Top5}} \text{Net Flow}_{b, s, T-k}$ | `0.0` | 5-day rolling cumulative net flow of Top 5 domestic brokerages in sector $s$. |
| `feat_sector_bofa_flow_zscore_20d` | Z-Score ($T-1$) | $\frac{\text{Flow}_{\text{MLB}, s, T-1} - \mu_{s, 20d}}{\sigma_{s, 20d} + \epsilon}$ | `0.0` | Statistical Z-score of sector flow ($|Z| > 2.0$ marks extreme sector positioning). |

---

### Cluster 5: Macro Context, Rates & Seasonality
*Cross-sectional macroeconomic regime, interest rate sensitivity, and recurring weekly execution patterns.*

| Feature Name | Type / Lag | Mathematical / SQL Formulation | Default / Coalesce | Microstructure & Behavioral Rationale |
| :--- | :--- | :--- | :--- | :--- |
| `feat_macro_bofa_prev_day_net_flow_tl` | Flow ($T-1$) | $\text{Net Flow}_{\text{MLB}, \text{Market}, T-1}$ | `0.0` | BofA's exchange-wide total net flow (macro risk-on / risk-off baseline). |
| `feat_macro_top5_prev_day_net_flow_tl` | Flow ($T-1$) | $\sum_{b \in \text{Top5}} \text{Net Flow}_{b, \text{Market}, T-1}$ | `0.0` | Domestic institutions' exchange-wide total net flow. |
| `feat_macro_interest_rate` | Level ($T-1$) | $\text{Rate}_{T-1}$ (TCMB 1-Week Repo %) | `45.0` | Baseline policy rate and cross-sectional cost hurdle across all sectors. |
| `feat_macro_rate_shock_decay` | Impulse ($T-1$) | $\frac{\Delta\text{Rate}_{\text{bps}, T-1}}{\max(1, \text{days\_since\_change}_{T-1})}$ | `0.0` | Decay-weighted rate shock impulse ($100\%$ on $T=0,1$, decaying at $1/d$ on $T \ge 2$). |
| `feat_macro_rate_spread_vs_30d_mean` | Delta ($T-1$) | $(\text{Rate}_{T-1} - \overline{\text{Rate}}_{30d, T-1}) \times 100$ | `0.0` | Policy stance vs 30-day moving average (tightening vs easing cycle). |
| `feat_sector_rate_x_flow_interaction` | Interaction ($T-1$) | $\frac{\text{Flow}_{\text{MLB}, s, T-1} \times \text{Rate}_{T-1}}{100}$ | `0.0` | Interaction between sector flow and policy rate (amplifies impact on high-flow sectors). |
| `day_of_week` | Integer ($T$) | $\text{DayOfWeek}(\text{trade\_date})$ | `1..5` | Day of week integer ($1 = \text{Monday}, \dots, 5 = \text{Friday}$). |
| `is_monday` | Binary ($T$) | $\text{day\_of\_week} = 1$ | `FALSE` | Monday session indicator (weekly sector re-allocation). |
| `is_friday` | Binary ($T$) | $\text{day\_of\_week} = 5$ | `FALSE` | Friday session indicator (weekend sector risk trimming / hedging). |

| Feature Name | Type / Lag | Mathematical / SQL Formulation | Default / Coalesce | Microstructure & Behavioral Rationale |
| :--- | :--- | :--- | :--- | :--- |
| `feat_sector_rel_return_vs_bist30_1d` | Alpha ($T-1$) | $\text{Return}_{s, 1d, T-1} - \text{Return}_{\text{XU030}, 1d, T-1}$ | `0.0` | 1-day excess return (alpha) of sector $s$ relative to BIST 30 benchmark. |
| `feat_sector_rel_return_vs_bist30_5d` | Alpha ($T-1$) | $\text{Return}_{s, 5d, T-1} - \text{Return}_{\text{XU030}, 5d, T-1}$ | `0.0` | 5-day rolling relative outperformance/underperformance vs benchmark index. |
| `feat_bist30_market_return_1d` | Return ($T-1$) | $\text{Return}_{\text{XU030}, 1d, T-1}$ | `0.0` | Broad market benchmark return (macro tailwind/headwind indicator). |
| `feat_bist30_market_range_pct` | Volatility ($T-1$) | $\text{Range}_{\text{XU030}, 1d, T-1}$ | `0.0` | Broad market benchmark price range % measuring market-wide volatility. |
| `feat_sector_beta_x_bist30_momentum` | Interaction ($T-1$) | $\text{MarketShare}_{\text{MLB}, s, T-1} \times \text{Return}_{\text{XU030}, 5d, T-1}$ | `0.0` | Interaction of BofA's sector market dominance with benchmark momentum. |

---

### Cluster 7: Sector Institutional FIFO Tertip & Inventory
*Tracks BofA's sector-level open positions, sector wallet inventory share, sector unrealized PnL, and competitor sector inventory delta.*

| Feature Name | Type / Lag | Mathematical / SQL Formulation | Default / Coalesce | Microstructure & Behavioral Rationale |
| :--- | :--- | :--- | :--- | :--- |
| `feat_sector_bofa_net_inventory_tl` | Level ($T-1$) | $\sum_{i \in s} (\text{Cost}_{\text{Long}} - \text{Cost}_{\text{Short}})$ | `0.0` | Signed total cost value of BofA's overnight open positions in sector $s$. |
| `feat_sector_bofa_inventory_wallet_share` | Ratio ($T-1$) | $\frac{\|\text{NetInv}_{\text{MLB}, s}\|}{\sum_k \|\text{NetInv}_{\text{MLB}, k}\|} $ | `0.0` | Proportion of BofA's total multi-sector carried inventory allocated to sector $s$. |
| `feat_sector_bofa_unrealized_pnl_tl` | PnL ($T-1$) | $\sum_{i \in s} \text{Unrealized PnL}_{T-1}$ | `0.0` | Mark-to-market unrealized PnL across open positions in sector $s$. |
| `feat_sector_bofa_unrealized_pnl_return_pct` | Return ($T-1$) | $\frac{\sum_{i \in s} \text{Unrealized PnL}}{\sum_{i \in s} \text{Gross Open Cost}} \times 100$ | `0.0` | Overnight return % on carried sector exposure. High gains trigger morning profit-taking. |
| `feat_sector_bofa_vs_top5_inventory_delta_tl` | Delta ($T-1$) | $\text{SectorNetInv}_{\text{MLB}} - \text{SectorNetInv}_{\text{Top5}}$ | `0.0` | Sector inventory divergence between BofA and Top-5 domestic dealer desks. |

## 4. Feature Selection, Configuration & Ablation Engine

All 32 sector feature columns are declaratively managed in `config/features.yaml` under `sector_day_start`.

### Configuration (`config/features.yaml`)
```yaml
sector_day_start:
  exclude_features: []
  include_features: []
  clusters:
    sector_closing_momentum: { enabled: true }
    sector_competitor_imbalance: { enabled: true }
    sector_dominance: { enabled: true }
    sector_accumulation: { enabled: true }
    macro_context: { enabled: true }
    benchmark_relative_alpha: { enabled: true }
    sector_tertip_inventory: { enabled: true }
```

### Programmatic & CLI Usage

#### Python / Jupyter Notebooks
```python
from mdk_trading_oracle.models.sector_day_start.forecaster import SectorDayStartForecaster

# Exclude specific features or disable clusters
forecaster = SectorDayStartForecaster(
    exclude_features=["feat_macro_rate_shock_decay"],
    disabled_clusters=["benchmark_relative_alpha"],
)
forecasts = forecaster.forecast_next_day()

# Run automated Leave-One-Cluster-Out (LOCO) ablation study across sectors
ablation_df = forecaster.run_ablation_study()
```

```bash

.venv/bin/python scripts/run_pipeline.py --target gold --disabled-clusters benchmark_relative_alpha
```
